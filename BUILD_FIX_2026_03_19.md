# Build Fix - March 19, 2026

## Issue
The project was failing to build with the following critical error:

```
/home/justin/repos/urban-sniffle/src/index-editor/App.axaml.cs(33,37): error CS0104: 
'LogLevel' is an ambiguous reference between 'IndexEditor.Shared.LogLevel' and 
'Microsoft.Extensions.Logging.LogLevel'
```

## Root Cause
In `App.axaml.cs`, two different `LogLevel` types were in scope:
- `IndexEditor.Shared.LogLevel` (from the using statement `using IndexEditor.Shared;`)
- `Microsoft.Extensions.Logging.LogLevel` (from `using Microsoft.Extensions.Logging;`)

On line 33, the code used `LogLevel.Debug` without qualification, causing the compiler to be unable to determine which type was intended.

## Solution
Changed line 33 from:
```csharp
builder.SetMinimumLevel(LogLevel.Debug);
```

To:
```csharp
builder.SetMinimumLevel(Microsoft.Extensions.Logging.LogLevel.Debug);
```

This explicitly specifies that we want the `Microsoft.Extensions.Logging.LogLevel` enum, not the `IndexEditor.Shared.LogLevel` enum.
